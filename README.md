A professional **inventory management dashboard** (Vessa) with stock tracking, product listings, low-stock alerts and analytics. Pure HTML, CSS & JavaScript.

---

## ✨ Features

- 📦 **Stock level tracking** with visual indicators
- ⚠️ **Low stock alerts** — automatic threshold warnings
- 🗂️ **Product listings** with search & filter
- 📊 **Inventory analytics** — turnover, value, categories
- 🏷️ **Category management** with status badges
- 🌙 **Dark themed** professional UI
- 📱 **Fully responsive** — works on all screen sizes
- ⚡ **Zero dependencies** — no libraries
